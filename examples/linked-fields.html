Связанные поля

Атрибут data-parent связывает поля: пока в родителе ничего не выбрано, дочернее выключено, а после выбора виджет сам якорит поиск по fias_id и переходит на уровень детей. Правка родителя сбрасывает цепочку. JavaScript для этого не нужен.

Заполнение соседних полей

Одно поле раскладывает выбранный объект по остальным через data-fill-* — в корзине так заполняют индекс и город, не показывая их отдельными подсказками.
